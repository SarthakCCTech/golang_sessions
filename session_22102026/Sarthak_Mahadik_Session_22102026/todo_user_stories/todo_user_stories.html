US-0014 criteria

Create a Todo

User StoryAs a user, I want to create a task so that I have a record of tasks that need to be done.
Acceptance criteria (4)
  1. The user can create a todo by providing the necessary information.
  2. The user is notified when required information is missing or invalid.
  3. The new todo is added to the user's todo list.
  4. The user receives feedback about whether the todo was created successfully.
US-0024 criteria

View Todos

User StoryAs a user, I want to view my todos so that I can identify what I need to do.
Acceptance criteria (4)
  1. The user can view their todos.
  2. Each todo displays its relevant information.
  3. Todos are arranged from the most recently created to the oldest.
  4. The user is notified when there are no todos available.
US-0035 criteria

Update a Todo

User StoryAs a user, I want to update an existing todo so that I can keep its information up to date.
Acceptance criteria (5)
  1. The user can select and update an existing todo.
  2. The user can modify the todo's information.
  3. The user is notified when required information is missing or invalid.
  4. The updated information is reflected in the todo after a successful update.
  5. The user is notified when the todo they want to update cannot be found.
US-0044 criteria

Delete a Todo

User StoryAs a user, I want to delete a todo so that I can remove tasks that are no longer needed.
Acceptance criteria (4)
  1. The user can select an existing todo for deletion.
  2. The user can confirm or cancel the deletion.
  3. The deleted todo no longer appears in the todo list.
  4. The user receives feedback about whether the deletion was successful.
US-0054 criteria

Search Todos

User StoryAs a user, I want to search for todos so that I can quickly locate a specific task.
Acceptance criteria (4)
  1. The user can search for a todo by its ID or title.
  2. The user can view todos that match the search criteria.
  3. The user is notified when no matching todos are found.
  4. The user can return to the full todo list after searching.
US-0065 criteria

Filter Todos

User StoryAs a user, I want to filter my todos by status or priority so that I can focus on specific tasks.
Acceptance criteria (5)
  1. The user can filter todos by completion status.
  2. The user can filter todos by priority.
  3. The user can view todos that match the selected criteria.
  4. The user is notified when no todos match the selected criteria.
  5. The user can clear the filters and view all todos.
US-0073 criteria

Mark a Todo as Completed

User StoryAs a user, I want to mark a todo as completed so that I can track the tasks I have finished.
Acceptance criteria (3)
  1. The user can mark a todo as completed.
  2. The user can mark a completed todo as pending again.
  3. The updated status is reflected in the todo list.
US-0084 criteria

Categorize Todos

User StoryAs a user, I want to assign categories to my todos so that I can organize tasks by topic.
Acceptance criteria (4)
  1. The user can assign a category to a todo.
  2. The user can view the category of a todo.
  3. The user can change a todo's category.
  4. The user can filter todos by category.
US-0093 criteria

Manage User Profile

User StoryAs a user, I want to manage my profile so that I can keep my personal information up to date.
Acceptance criteria (3)
  1. The user can view their profile information.

US-0104 criteria

User Login and Logout

User StoryAs a user, I want to log in and log out securely so that my todos are accessible only through my account.
Acceptance criteria (4)
  1. The user can log in with valid credentials.
  2. The user is notified when login credentials are invalid.
  3. The user can log out of their account.
  4. The user cannot access another user's todos.
